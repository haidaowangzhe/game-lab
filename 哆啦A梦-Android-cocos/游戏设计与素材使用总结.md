# 《哆啦A梦跑酷》设计与素材使用总结

本文档对已完成设计与当前工程实现做通览：设计思路、素材用法、关键参数、局内玩法与页面放置。权威细则仍以 [`设计说明书/`](设计说明书/)、[`完整设计图/`](完整设计图/)、[`素材/`](素材/) 为准；可运行逻辑以 [`../Doraemon Parkour-游戏源码/`](../Doraemon%20Parkour-游戏源码/) 为准。

路径均为相对本文件（`设计资料/`）的 Markdown 链接，悬停／点击可预览图片或打开文档。真机／模拟器截图见 [`效果图/`](效果图/)。

**素材清单写法约定：**

- **常驻**：同屏固定出现的控件／底图，逐条列出。
- **素材族（条件／互斥）**：同槽位按状态、角色、商品等切换、**不会一次性全部展示**的资源，必须单独成族：先写清「同时显示几张／按何条件切换」，再列成员；禁止把族成员与常驻素材混成一张「好像全在页上」的表。

**放置坐标写法约定（便于改分辨率时整组平移／缩放，不必逐图手调）：**

1. **画布原点**：各页 `ProportionalCanvas` 设计坐标，左上为 `(0,0)`，右下为 `(宽,高)`。整页先等比 `scale` 再贴屏，故**改屏宽高只需改 canvas／scale，画布内坐标可保持不动**。
2. **绝对锚点页**（源码用 `.position(x,y)`）：必须写清是**中心点**还是左上角，并给出 `frame` 宽高。例：加载页、结算面板内元素、暂停按钮列、通关特效。
3. **流式布局页**（源码用 `VStack`／`HStack` + `padding`／`spacing`／`offset`）：必须给出**放置契约**（哪一组、哪些 padding／spacing／offset）。这些参数即「整组旋钮」——例如只改首页 `VStack.offset(y:)` 即可上下平移全部控件。另附**推算左上角**（由契约算术得到，标「推算」），方便对照设计图。
4. **不可固定坐标**：局内世界实体／掉落／终点门随摄像机与生成变化；仅写映射公式或尺寸，不写死屏坐标。背景全屏 `.fill` 无 UI 锚点。
5. 第三节 **3.1–3.17** 为逐页施工图（坐标／素材／用否）；**四～七**为跨页归纳与 **Cocos 移植总表**（画布、流程、经济、勿导清单、验收）；**八**为说明书索引。

## 一、整体设计思路

### 1.1 产品定位

- 横屏 2D 像素风跑酷；主角为哆啦A梦系列角色。
- 中文界面；App Identity（Target／Display Name／Bundle ID）用英文或拼音：`Doraemon Parkour`／`com.itzzw.doraemonparkour`。
- 纯单机、当前版本无充值；金币与钻石全靠游玩获得。
- 视觉：金边蓝宝石装饰 UI + 像素角色／场景；App 图标为 [`素材/App图标/app_icon_1024.png`](素材/App图标/app_icon_1024.png)（1024×1024）。

### 1.2 信息架构（五类页面）

1. 启动与入口：加载页、首页  
2. 关卡流程：关卡选择、局内 HUD、暂停、结算（设置／关于／隐私从多入口进入）  
3. 资产管理：背包角色／道具／宝箱  
4. 商城购买：角色／道具／宝箱钥匙列表 + 三类详情  
5. 功能反馈弹窗：暂停、开箱奖励、钥匙／宝箱不足、充值提示  

共约 22 张完整设计图覆盖上述结构。实现后的模拟器截图见 [`效果图/`](效果图/)，共 22 张，编号 `01`–`22`，与第三节逐页对照。

### 1.3 核心循环

```text
加载 → 首页 → 关卡选择 → 局内跑酷（携带道具／拾取／机关）
  → 结算入账 → 背包管理／开箱 → 商城补充 → 再闯关
```

经济闭环：金币管日常消耗与中低阶箱钥；钻石管角色与紫金箱钥；一件商品只收一种货币，二者不可互换。

### 1.5 运行时素材路径约定（重要）

代码**从不**按磁盘随意找图，统一走 `AssetPath.image` / `AssetPath.data`（`Services/AssetImage.swift`）：

1. Xcode 把 [`设计资料/素材`](素材/) 整夹拷进 App Bundle（`project.pbxproj`：`path = "../设计资料/素材"`）。
2. 源码里写的相对路径**不含** `素材/` 前缀，例如 `"首页/背景图.png"`。
3. 加载时自动拼成 Bundle 内：`素材/` + 相对路径 → 磁盘对应  
   `设计资料/素材/首页/背景图.png`。

### 1.7 全局放置与比例通则

- 背景铺满物理屏幕；交互控件避让刘海／灵动岛／Home Indicator，不因安全区整体推移背景。
- 按钮点击区建议 ≥ 44 pt；禁用态降亮／灰／半透明且不可点。
- 分类栏按钮必须落在栏内空白区，不压边框与角落装饰。
- 详情底板文案 ≤ 20 字；价格／钥匙数字落在价格条或底板空白内。
- 弹层居中；底部确定／操作按钮位置固定，中部内容再多也只在区域内排布或滚动，不挤压底栏。
- 人物高度：地面走动 : 直立飞行 : 倾斜飞行 = 1.5 : 2.35 : 2.2（见 [`人物素材高度比例规范.md`](素材/游戏内主界面/人物运动/人物素材高度比例规范.md)）。
- 道具快捷栏图标为「面板+道具」成品；空闲不显示；用后半透明不可再点（见 [`道具快捷栏设计.md`](素材/游戏内主界面/道具快捷栏/道具快捷栏设计.md)）。
- UI 用设计画布等比缩放（`ProportionalCanvas`）；局内世界以高度 637 为基准换算碰撞与落点。

## 二、关键数值与系统参数

### 2.1 货币与初始档

- 金币：道具、木／银／黄金箱与铜／银／金钥匙；出售道具只回金币（售价 = 买价 50%）。
- 钻石：付费角色、紫金箱、紫钥匙。
- 界面只显示金币、钻石两种数量。
- 开箱消耗：1 箱 + 1 对应钥匙，不另扣币；钥匙库存上限 99。
- 新档默认：金币 200、钻石 10；已解锁／出战角色为哆啦A梦；道具库存含迷你铜锣烧 ×2、能量牛奶 ×1。

### 2.3 携带与快捷栏

- 每局最多 3 格；每格 1 个；同种最多 1 格；专属食物须匹配当前出战角色。
- 背包「使用」= 从库存扣 1 并写入携带；取消携带退回库存。
- 局内右缘竖排：上方为能量满时的大招图标（不占 3 格）；其下为「本局拾取道具」与「携带道具」；超过 3 个普通格可竖向滑动。
- 携带道具用后半透明不可再点；未使用的携带项在结算时退回背包。
- **素材族：快捷栏成品图标**（按携带／拾取出现，空闲不显示；目录非同屏全铺）：[`特殊道具/`](素材/游戏内主界面/道具快捷栏/特殊道具/)、[`通用道具/`](素材/游戏内主界面/道具快捷栏/通用道具/)、[`食物道具/`](素材/游戏内主界面/道具快捷栏/食物道具/)。

### 2.6 道具效果（局内实现）

特殊：急救箱立即 +3 心；活力饮料先 +1 心，约 2.5 秒后再 +1；幸运饮料 20 秒（金币拾取 ×2）；飞跃饮料 15 秒（移速／跳跃 ×1.2）。

叠加表现见 [`道具使用叠加效果设计.md`](素材/游戏内主界面/道具快捷栏/道具使用叠加效果设计.md)。

### 2.7 关卡与跑酷参数（实现）

- 关卡 1–20；通关成功解锁下一关（上限 20）。
- 目标距离：约 `330 + 关卡×18` 米；同关固定种子，重玩布局可学习。
- 移速受关卡、角色运动属性、飞跃／跑鞋／大雄能量加成影响；支持左右移动、双段跳、飞行升降。
- 终点大门完整入镜后锁镜头，播通关特效约 2.8 秒再进结算。
- 星级：通关后按得分相对目标距离比值与剩余血心判定 1／2／3 星。
- 机关随关卡逐步解锁（滚石、地刺、箭矢、侧刺、吊链落刺等）；悬浮台、宝箱、货币与道具按区段概率生成。掉落口径见 [`游戏过程中物品出现概率设计.md`](素材/游戏内主界面/游戏内随机掉落素材/游戏过程中物品出现概率设计.md)。

### 2.8 结算奖励（实现摘要）

细则流程见 [`结算奖励设计.md`](素材/结算页/结算奖励设计.md)；实现要点：

- 失败：入账本局拾取；若一无所获给 10 金币安慰奖。
- 成功：拾取 + 通关基础金币（按关卡区间约 40／70／100／130）+ 星级加成（2 星 +25／3 星 +55）+ 首通金币与钻石 + 可能的额外钻石（3 星低概率）+ 累计通关节点箱钥。

#### 3.1.1 页面职责与流程逻辑

冷启动品牌页：无按钮、无点击。进入后自动跑进度动画，结束后切到首页。

实现流程（源码）：

1. App 启动 → `DoraemonParkourApp` 注入 `GameAppState` → `RootView` 因 `screen == .loading` 显示 `LoadingView`
2. `LoadingView` 出现后执行 `.task`：
   - 普通运行：`progress` 从 `1/30` 步进到 `30/30`（共 30 步）
   - 每步 `Task.sleep(nanoseconds: 45_000_000)`，即 **45 ms**
   - 总时长约 **30 × 45 ms = 1.35 s**
3. 步进结束后调用 `state.completeLoading()` → 内部 `navigate(.home)`
4. `navigate(.home)` 将 `screen` 设为 `.home`，并播放首页 BGM `bgm_home`（`loading` 分支本身不切歌）

DEBUG 特例：启动参数含 `-uiTestLoading` 时，`progress` 固定为 `0.68` 并 `return`，不自动进首页（便于截图／UI 测试）。

| --- | --- |
| 返回 | `navigate(.home)`（无额外 `sfx_tap`；`Button` 未套 `GameHapticButtonStyle`） |
| 设置 | `openSettings(from: .levels)` → 设置遮罩；`returnScreen = .levels` |
| 上一页 | `page = max(0, page - 1)`；`page == 0` 时 `disabled`；有触觉 |
| 下一页 | `page = min(1, page + 1)`；`page == 1` 时 `disabled`；有触觉 |
| 关卡格 | 已解锁：`startLevel(level)` → 进局内；未解锁：`disabled`，点不到 |

`startLevel`：若 `level > unlockedLevel` 会 toast「该关卡尚未解锁」（格子已 `disabled`，正常点不到）。成功则 `selectedLevel`／新 `runSessionID`／`navigate(.run)`／`bgm_run`。

分页数据：`pageLevels` = `start = page×15+1` … `min(start+14, 20)`；`start > 20` 则空。

格子状态（`LevelTile`）：

- `unlocked = level <= profile.unlockedLevel`
- `stars = profile.levelStars["\(level)"] ?? 0`
- 底板：未解锁 → 锁定；`stars > 0` → 白底；否则灰底（已解锁未通关或通关 0 星——实现上通关至少会写星级，见结算；灰底主要表示「已开未玩」）
- 数字：仅 `unlocked` 时显示关号；有星时数字 `offset(y: -12)`，三星条 `offset(y: 25)`
- 星条：仅 `stars > 0` 时显示 3 槽，第 `i` 槽：`i < stars` 金星否则灰星

进入本页时：`navigate(.levels)` 走 `default` 分支，播 `bgm_home`（与首页同 BGM）。

#### 3.5.1 页面职责与交互逻辑

局内半透明遮罩上的菜单：继续、重开、设置、回首页。出现期间 `RunGameViewModel` 主循环因 `isPaused` 不再推进（移动／碰撞／计时停）。

| 控件 | 源码动作 |
| --- | --- |
| 继续游戏 | `vm.togglePause()` → `isPaused = false`，遮罩消失 |
| 重新开始 | `state.restartLevel()` → 新 `runSessionID` + `navigate(.run)`（同关重开，新会话） |
| 设置 | `openSettings(from: .run)` → 设置遮罩叠在最上层；`returnScreen = .run` |
| 返回主页 | `navigate(.home)`（不经结算；本局进度不入账） |

按钮均 `GameHapticButtonStyle`；`art` 未另播 `sfx_tap`。

**自动暂停（无 PauseView 面板时也会停表）**

- `showSettingsOverlay`／`showInventoryOverlay` 变化时：`vm.isPaused = $0`
- 故局内开设置／背包会暂停；**关闭后 `isPaused` 被设为 false**，会一并收起 PauseView（若当时因暂停钮打开过）。从暂停进设置再关掉设置，等价于继续游戏。

DEBUG：启动参数含 `-uiTestPause` 时，`isPaused` 初始为 true，便于截图。

#### 3.5.2 布局坐标系（实现精确值）

**布局类型：面板固定尺寸 + 按钮列绝对中心；外层 ModalMask 居中。**

- `ModalMask`：全屏黑 **0.55**；内容 `padding(16)`，max 宽高 `min(920,W-24)`／`min(660,H-16)` —— **只约束外壳，不改面板内坐标**

| 元素 | 锚点含义 | 坐标 | frame |

| 暂停面板.png | 铺满面板 | 左上 (0,0) | 250×340 |
| 按钮列 `VStack` | **中心** `.position(x:125, y:180)` | 中心 **(125, 180)** | 列总高见下 |
| 继续／重开／设置／回首页 | 列内自上而下，`spacing: 6`，各钮中心 x=125 | 见下表 | 各 **190×50** |

| 按钮 | 中心 (x,y) | 推算左上 (x,y) |

| 设置 | (125, 152+56)=(125, **208**) | (30, 183) |

#### 3.7.1 页面职责与交互逻辑

| 控件 | 源码动作 |
| --- | --- |
| 音乐 ± | `changeVolume(music: true, delta: ±1)`，钳制 0–10，`persistSettings` |

| 清理缓存 | `clearCache()` → 清 `lastRunSummary`，保留进度；toast「缓存已清理，进度已保留」 |
| 隐私政策 | `showPrivacy = true` → §3.8 |

#### 3.10.1 页面职责与交互逻辑

只列出「库存 > 0 **或** 已在 `loadout`」的道具（`ownedItems`）；最多携带 3 格；出售单价 `sellPrice = buyPrice / 2`（金币）。

| 控件 | 源码动作 |
| --- | --- |
| 返回／+／设置 | 同 §3.9.1（充值 → §3.14；设置来源 `embedded ? .run : .inventory`） |
| 分类栏 | `inventoryCategory`；本页 **道具亮**，角色／宝箱灰 |
| 列表卡 | `selectedItemID = item.id`；角标 Text：`×(库存 + (在携带?1:0))` |
| 出售（亮） | `sell(id)`：库存 −1，金币 +`sellPrice`；toast「出售成功…」 |
| 出售（灰） | 库存 = 0（仅在携带栏时亦灰）；再点 toast「没有可出售的道具」 |
| 使用（亮） | `carry`：库存 −1 装入 loadout；专属角色不符 →「非当前角色专属」；已满 3 →「携带已满…」；无库存 →「背包中没有该道具」 |

### 4.1 目录分工（Cocos 资源怎么取）

| 目录 | 用途 | Cocos 建议 |

### 4.2 常驻／族／放置（复述约定）

- **常驻**：同屏固定出现 → 必导入。  
- **素材族**：同槽互斥或按条件出现 → 导入「可能亮起」的成员，并在代码里切换，**不要**当「全目录同屏」。  
- **放置**：第三节给了中心／推算左上／显示框；Cocos 用锚点 (0.5,0.5) 吃中心列，或锚点左上吃推算列。  
- **改屏**：先改画布宽高与整页 `scale`，勿逐控件改数。

### 4.3 文案两套路

| 类型 | 做法 |
| --- | --- |
| 烘焙进 PNG | 改字必须出新图（面板标题、分类钮字等） |
| 运行时 Text／Label | 落在文档「框」内；价、库存、页码、简介、技能等 |

### 4.4 缩放公式（建议做成唯一 UI 根组件）

```text
scale = min(可视宽 / 设计宽, 可视高 / 设计高)
节点世界坐标 = 设计坐标 × scale
另有页内 scaleEffect 时：最终 = 设计坐标 × 页内scale × 根scale
```

全屏背景可单独 `FILL`，不进 UI 画布（加载／首页／选关／局内背景均如此）。

## 五、页面关系与状态机

### 5.1 主流程

```text
Boot/Loading
  → Home
      → LevelSelect → Run ⇄ Pause
                      Run → Result → Home / LevelSelect / Inventory / Shop
      → Inventory（角色|道具|宝箱）
            → ChestReward / ChestFail →（失败「商店」）Shop.chests
      → Shop（角色|道具|箱钥）→ ProductDetail → 扣费回列表
      → Settings ⇄ About | Privacy
任意「+」→ RechargePrompt（无支付，仅关闭）
局内亦可叠：Settings / Inventory / Recharge
```

### 5.2 叠层规则（Modal）

| 层 | 典型 | 说明 |
