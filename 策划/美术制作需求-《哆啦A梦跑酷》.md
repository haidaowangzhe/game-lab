## 1. 整体风格

| 项 | 要求 |
|----|------|
| 视角 | 横屏 2D |
| 角色与场景 | 哆啦A梦 IP 休闲跑酷，像素风 |
| UI | 金边 + 蓝宝石装饰；圆角框、宝石质感按钮；中文 |
| 色调 | 界面明亮；局内天空与远景偏蓝白清爽，与 UI 金蓝同系 |
| 格式 | PNG，透明底（全屏背景可不透明）；保持像素清晰 |
| 分辨率 | 全屏背景约 1850×850；UI 按设计稿出图，程序等比缩放 |
| 应用图标 | 1024×1024，文件名 `app_icon_1024.png` |

**统一视觉关键词：** 横屏 2D、哆啦A梦休闲跑酷、像素角色、金边蓝宝石 UI、明亮、PNG 透明底。

素材清单分 **常驻**（同屏固定）与 **素材族**（同槽位多状态：血心、能量条、按钮正常/禁用）。

## 2. 目录与命名

全部放入 `assets/resources/素材/`，相对路径即程序加载 ID（例：`首页/背景图.png`）。

```text
素材/
├── App图标/
├── 加载页/
├── 首页/
├── 关卡选择页/
├── 游戏内主界面/
│   ├── 人物运动/
│   ├── 关卡机关与障碍素材/
│   ├── 道具快捷栏/
│   └── …
├── 结算页/
├── 背包页/
├── 商城页/
├── 设置页/
├── 暂停页/
├── 充值提示页/
├── 游戏信息+隐私政策/
└── 货币显示框/
```

文件名稳定、语义清晰；资源迭代时 **覆盖同名文件**，路径保持不变。

## 3. 角色 · 道具 · UI 态

**可出战角色（局内全套动作）：** 哆啦A梦、大雄、静香、哆啦美——地面行走；飞行靴/大招：直立飞、倾斜飞。

**人物有效高度比：** 地面 walk : 直立飞 : 倾斜飞 = **1.5 : 2.35 : 2.2**（例：地面 120px → 直立约 188px、倾斜约 176px）。

**快捷栏：** 「底框 + 道具」合成 PNG，目录 `道具快捷栏/特殊道具`、`通用道具`、`食物道具`。同系列食物源图尺寸可不同，保持比例供程序等比缩放。

**局内携带格：** 提供正常态与禁用态底图；已消耗时程序叠加半透明，禁用态仍须可辨认道具。

| UI 态 | 要求 |
|-------|------|
| 正常 | 全彩 |
| 禁用 | 灰度或明显降饱和 |

交互热区视觉范围不小于约 44pt 等效。

## 4. 分模块素材

### 4.1 加载与首页

| 模块 | 常驻 / 族 | 需产出 |
|------|-----------|--------|
| 加载页 | 常驻 | 全屏背景、进度条底+填充、Logo/标题 |
| 首页 | 常驻 | 背景、开始/选关/设置、商城/背包入口、金币/钻石货币框 |
| 首页 | 族 | 可出战角色方头像（§3 四名） |

### 4.2 选关、局内 HUD、暂停、结算

| 模块 | 常驻 / 族 | 需产出 |
|------|-----------|--------|
| 选关 | 常驻 | 背景、返回/设置、关卡格 1–20、翻页 |
| 选关 | 族 | 未解锁/已解锁；星级亮/暗 |
| 局内 HUD | 常驻 | 可横向拼接/滚动的背景层、暂停、回首页/背包、四向操作键 |
| 局内 HUD | 族 | 生命 5 槽红心/灰心；能量条底、填充黄→深绿各档、空/灰态 |
| 局内 | 常驻 | 距离与得分区底框（或与 HUD 合成） |
| 结算 | 常驻 | 成功与失败两套面板底（或同结构差异化）、三颗星、重试/主页/下一关 |
| 结算 | 族 | 下一关可用/禁用；星级亮/暗 |
| 暂停弹层 | 常驻 | 与局内 HUD 同风格；继续、重开本关、回主页 |

### 4.3 局内玩法向素材

| 类别 | 需产出 |
|------|--------|
| 人物 | §3 四名角色动作图 |
| 障碍 | 货箱、滚石、蓝/红桶、水泥、石墙、大石等（与策划配表主障碍一致） |
| 陷阱 | 地刺、滚石、箭矢（上下左右）、墙刺、链刺等 |
| 平台 | 悬浮台切片 1–4，可横向拼接 |
| 掉落 | 金币组、四色宝石、木箱、各道具与食物局内小图标 |
| 快捷栏 | §3 成品图标；大招图标 |
| 终点 | 终点门；通关演出特效帧（约 2.8s，程序驱动） |

### 4.4 背包

面板底、关闭、道具/角色/宝箱三 Tab（正常/选中）；角色立绘或大图、头像、选中框、未解锁灰态；道具列表格、详情底、使用/出售（亮/禁用）；木/银/金/紫金箱与对应钥匙、开箱按钮；开箱结果与缺箱/缺钥提示图。

### 4.5 商城

面板、关闭；角色/道具/箱钥分类 Tab（可用/不可用）；货架商品卡（含可出战四人及胖虎、小夫 **展示用头像**）；详情页（角色属性宝石亮/灰、道具/箱钥说明区、购买钮、价格条）。文案区留白（短说明 ≤13 字、详情 ≤20 字，策划案 1.4）。

### 4.6 设置与弹层

设置页：面板、音量滑条与框、震动与提示开关、恢复默认、清缓存、关于与隐私入口、退出。关于/隐私滚动弹窗；充值说明小弹窗（纯说明，对应策划案充值提示页）。

## 5. 音频

放入 `assets/resources/audio/`。

| 类型 | 要求 |
|------|------|
| BGM | 一条轻快循环曲，全游戏共用，切页不换轨 |
| SFX | 按钮、受伤、通关成功/失败、开箱等；格式 m4a 或 wav，目标平台可播 |
