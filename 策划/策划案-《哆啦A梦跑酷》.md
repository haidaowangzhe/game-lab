**当前范围（第一版）：** 横屏跑酷，20 关，单机无充值。

**撰写思路（我平时的顺序）：**

# 第一部分 · 整体规则

## 1.1 项目定位

| 项 | 当前设定 |
|----|----------|
| 类型 | 2D 像素风横屏跑酷 + 轻度养成 |
| 单局 | 跑目标距离、躲障碍、拾取、决定何时用道具与大招 |
| 局外 | 金币买道具和箱钥，钻石解锁角色和紫金箱钥 |
| 硬约束 | 金币与钻石不互兑；一种商品只收一种货币；无内购 |

---

## 1.2 核心循环

```text
加载 → 首页
  → 选关，或「开始游戏」（进当前已解锁的最高关）
  → 局内跑酷
  → 结算（资源入账、星级记录）
  → 背包（携带 / 开箱）或商城（购买）
  → 再闯关
```

**要什么效果：** 打一局有清晰成败和星级；局外能感到钱/钻、背包在变，下一局能带不同东西。  
**怎么做成：** 结算多层奖励入账；商城/背包改库存；进关读携带栏与出战角色。

---

## 1.3 模块清单

- 页面：加载、首页、选关、局内、结算、背包、商城  
- 弹层：设置、关于、隐私、充值说明、暂停、局内背包、商城四类详情、开箱成功/失败  
- 局内：移动与跳跃、障碍与陷阱、平台、掉落、血心、能量与大招、得分与星级  
- 角色：6 人档案，4 人可出战  
- 道具：特殊 / 通用 / 食物；携带；快捷栏  
- 经济：双货币、分层结算、首通与节点、满 3 星关掉落限制  
- 进度：通关解锁、星级记录  
- 设置与本地存档  

---

## 1.4 全局 UI 约定

- 横屏；背景铺满；可点区域尽量 ≥ 44pt。  
- 多页顶栏显示金币、钻石。  
- 禁用：灰图且不可点。  
- 详情短文案 ≤20 字；商城卡片短效果 ≤13 字。  
- 商城、背包：叠在首页背景 + 半透明遮罩。

---

## 1.5 系统串联

```text
关卡进度
    ↓
局内（操作 / 掉落 / 星级 / 携带与拾取）
    ↓
结算入账（拾取 + 基础 + 星 + 首通 + 节点）
    ↓
金币线：商城 → 背包 → 携带 → 再进局内
钻石线：商城角色 / 紫金 → 换体验 → 再进局内
```

改一处时顺着这条链想会不会牵连别的模块。

## 1.6 经济规则（双币、结算、开箱、定价）

### 双货币

**要什么效果：** 金币今天能花；钻石攒几天解锁角色或开紫金；扣款不会混两种币。  
**怎么做成：**

| 货币 | 主要用途 |
|------|----------|
| 金币 | 道具，木/银/黄金箱，铜/银/金钥匙；卖道具只回金币 |
| 钻石 | 角色解锁，紫金箱，紫钥匙 |

不可互兑、不可混付；开箱只扣 1 箱 + 1 把对应钥匙。

### 成功通关 · 结算叠加顺序

下面是要有的**层次**；各档金额、宝石折算、首通钻等**填数**在配表表7、表8、表0（由本文规则整理过去）。

| 顺序 | 内容 |
|------|------|
| ① | 本局拾取：金币直加；宝石折算；道具与木箱进背包 |
| ② | 通关基础金（低/中/高档） |
| ③ | 星级加成：2 星 +25 金，3 星 +55 金 |
| ④ | 首通金钻（每关仅一次） |
| ⑤ | 通关节点（每节点仅一次，见下表） |
| ⑥ | 3 星概率额外 +1 钻（可重复） |

**通关节点：**

| 首次通关 | 奖励 |
|----------|------|
| 第 3 关 | 木箱 + 铜钥 |
| 第 5 关 | 木箱 + 铜钥 + 10 钻 |
| 第 8 关 | 银箱 + 银钥 + 15 钻 |
| 第 12 关 | 银箱 + 银钥 + 20 钻 |
| 第 16 关 | 黄金箱 + 金钥 + 25 钻 |
| 第 20 关 | 黄金箱 + 金钥 + 30 钻 |

心算例（第 1 关，无拾取，3 星首通）：40 + 55 + 30 = **125 金**，**3 钻**。

### 失败

只保留本局已拾取；不发基础/星/首通/节点；零拾取 +10 金安慰。

### 定价思路（改价时用）

- 金币：以单关首次高星通关为锚（如 125 金 → 最低消耗约 40 金 ≈ 三分之一）。  
- 钻石：粗验推 5～10 关能买第一个付费角色。  
- 单价、箱钥价：定价思路定在本节，**具体数字填配表**表2～4。

### 开箱（规则）

背包发起；箱、钥各 −1；按表5 roll；重复角色折金币；缺箱或缺钥不扣资源。

| 箱 | 产出感 |
|----|--------|
| 木 | 偏低，小食物/牛奶/跑鞋 |
| 银 | 中，中食物/功能道具，小概率钻或角色 |
| 黄金 | 偏高，稀有道具/高级食物 |
| 紫金 | 高，中高阶道具，钻包大 |

### 养成两条线

| 线 | 路径 |
|----|------|
| 金币 | 结算 → 商城 → 背包携带 → 局内 |
| 钻石 | 结算 → 商城角色 → 换出战与大招 |

真机验收时，配表「验收对照」第二、五、六节是据本节拆的检查项。

## 1.7 道具与携带规则

### 为何要做携带

道具是进关前策略，局内自己决定何时用；不在背包一点就生效。

### 携带规则（全局）

| 规则 | 说明 |
|------|------|
| 格数 | 最多 3 格，每格 1 个，同种 1 格 |
| 背包「使用」 | 库存 −1，写入携带栏，不当场生效 |
| 卸下 | 已携带时再点「使用」，回库存 |
| 专属食物 | 须匹配出战角色 |
| 出售 | 买价 × 50%，只回金币 |

### 快捷栏（局内行为）

| 区域 | 行为 |
|------|------|
| 大招 | 能量满 5 格出现 |
| 拾取区 | 本关捡的，同种可堆叠，点用消耗 |
| 携带区 | 进关带的，用后半透明不可再点 |

结算：未用完的携带退回背包；已消耗不退。

### 道具局内效果（时长、买价在配表表2 填数）

| 类型 | 代表 | 效果 |
|------|------|------|
| 特殊 | 急救箱 | 立即 +3 心 |
| 特殊 | 活力饮料 | 先 +1，约 2.5 秒后再 +1 |
| 特殊 | 幸运/飞跃饮料 | 约 20s / 15s 收益或移速跳跃加成 |
| 通用 | 磁铁/盾/跑鞋/飞行靴/牛奶 | 吸附、挡 1 伤、加速、飞行、+1 心 |
| 食物 | 各角色三档 | +1/+2/+3 心，专属 |

不做「携带满替换」「背包一键使用」。

## 1.11 策划、配表与真机（分工 / 迭代 / 验收）

**从零做一版（我习惯的顺序）**

```text
本策划案（本文）
    ↓
数值配置表.xlsx（按本文拆 Sheet、填数、验收对照打勾）
    ↓
实现 → 真机 → 策划/配表/代码一起改
```

**分工**

| 写什么 | 放在哪 |
|--------|--------|
| 要什么体验、规则、公式与锚点、页面怎么串 | **本文（主文档）** |
| 关卡每一行、道具价、权重、掉落上限、验收打勾序号 | **数值配置表.xlsx**（本文的落地） |

**配表简称与工作表：** 本文中的表0～表8 与 xlsx 工作表对照见 **Sheet索引**（例：表0=全局常量，表1=关卡表，表1B=障碍解锁，表1C/表1E=路段参数，表1D/表6=掉落表，表7=结算分档，表8=通关节点；真机打勾见 **验收对照** Sheet）。

**迭代时怎么改**

1. 先判断：是**规则/流程**问题，还是**只调数**。  
2. **规则变了**（例：星级条件、携带格数、结算层次）→ **先改本文** → 再同步改配表与实现 → 真机。  
3. **规则不变，只调手感/经济**（例：第 3 关距离、牛奶价格）→ 改配表对应行 → 真机；若发现规则本身不对，仍回到本文。  
4. 纸面改完不算完，**以真机为准**。

**改完怎么验**

| 我改了… | 先对照本文… | 配表打勾… |
|---------|--------------|-----------|
| 页面跳转 | 第二部分 2.1～2.9 | — |
| 局内操作、星级、掉落 | 2.5 + 1.9 | 表1/1B/1C/1D/1E/6、验收·一、三 |
| 携带、快捷栏、道具效果 | 1.7 + 2.7 | 表2、验收·四 |
| 结算、商城、开箱 | 1.6 + 2.6～2.8 | 验收·二、五、六 |
| 某一关手感 | 2.5 + 1.9 | 表1、1B～1D、6 |

**最小走查：** 新档 → 第 1 关 3 星首通对结算 → 背包带 1 道具第 2 关用掉 → 商城买 1 件 → 有钥则开木箱 → 选关看星与解锁。

**体验不对时先看哪**

| 感觉不对 | 先看本文 | 再查配表 |
|----------|----------|----------|
| 某关太难或太水 | 1.9、2.5 | 表1、表1C |

# 第二部分 · 页面设计

## 2.1 页面跳转总表

| 页面 | 怎么进 | 怎么出 |
|------|--------|--------|
| 加载页 | 启动 | 自动 → 首页 |
| 首页 | 加载；结算回主页 | 开始→局内（**当前解锁最高关**）；选关→2.4；商城/背包→2.8/2.7；设置→2.9 |
| 选关页 | 首页 | 点关→局内；返回→首页 |

| 商城 | 首页 | 关闭→首页；商品→详情弹层 |

## 2.2 加载页

**要什么效果：** 冷启动有品牌感，无操作，很快进首页。  
**怎么做成：** 无按钮；进度动画结束后切首页（实现约 1～2 秒量级即可）。

---

## 2.3 首页

**要什么效果：** 一眼看到是谁出战、有多少钱、从哪开始玩、从哪进商城背包。  
**怎么做成：**

| 元素 | 行为 |
|------|------|
| 角色头像 | 当前出战角色 |
| 金币 / 钻石 | 读存档，多页同风格顶栏 |
| 商城 / 背包 | 进 2.8 / 2.7（带遮罩） |
| 开始游戏 | 进局内，关卡 = 已解锁最高关 |
| 关卡选择 | 进 2.4 |
| 设置 | 设置弹层 |

## 2.4 选关页

**要什么效果：** 看清打到哪、每关几星、哪些还能挑战。  
**怎么做成：**

- 20 关，分页 1–15 / 16–20；未解锁锁态不可点。  
- 已解锁显示历史最高星。  
- 顶栏：返回、设置、双货币。  
- 点关卡 → 该局内。

进度规则见 **1.9**。

## 2.5 局内

### 单局目标

HUD 显示当前/目标米数；到终点演出后进结算；血心 0 失败结算。距离公式见 **1.9**（逐关米数填配表表1）；同关固定种子。

### 操作

| 操作 | 效果 |
|------|------|
| 左 / 右 | 移动 |
| 上 | 跳、二段跳 |
| 下 | 飞行时快降 |
| 飞行靴 / 哆啦A梦大招 | 飞行段 |

### 血心、得分、星级

- 开局 5 心；碰撞扣心；护盾可挡 1 次。  
- 得分局内累加；通关后：得分比 = 得分 ÷（目标距离×7）；3 星需比 >1.05 且剩余心 ≥4；2 星 >0.65。  
- 星级写入存档，选关页展示。

### 能量与快捷栏

拾取涨能量，满 5 格出大招钮（见 **1.8**）。  
快捷栏：大招 / 拾取区 / 携带区，规则见 **1.7**。

### 关卡内容与掉落

- 主障碍、平台、障碍池：结构见 **1.9**，逐关/逐池填配表。  
- 掉落权重与上限：规则见 **1.9**，数填表6、1D。  

### HUD 布局

```text
左上：暂停、导航（首页/背包）
中上：距离、得分
左下：四向键
右上：血心、能量
右缘：快捷栏（可竖滑）
```

真机：快捷栏不挡方向键与导航。

## 2.6 结算页

**要什么效果：** 立刻知道赢/输、几星、本局得分；方便重试、下一关或回主页；未用掉的拾取能看清楚。  
**怎么做成：**

| 元素 | 行为 |
|------|------|
| 底框 | 成功 / 失败不同图 |
| 星级 | 3 颗星亮/灰 |
| 得分 | 数字展示 |
| 奖励卡 | 本局获得且未用掉的道具等；多则轮播 |
| 重试 | 同关再开 |
| 下一关 | 本关已成功且 &lt;20 关可用，否则灰 |
| 主页 | 回首页 |

入账规则（金币/钻怎么加）按 **1.6** 在进本页前算完；页面上主要是反馈，玩家应能对上心算。

---

## 2.7 背包页

**要什么效果：** 换角色、带道具、开箱，和局内用的是同一份数据。  
**怎么做成：**

| Tab | 内容与行为 |
|-----|------------|
| 角色 | 已解锁列表，选出战；不可出战灰态 |
| 道具 | 列表 → 详情：名称、≤20 字介绍、出售价；**使用=携带**（**1.7**）；出售 |
| 宝箱 | 箱钥数量；点开箱 → 成功 2.9 奖励层 / 失败 2.9 |

局内从导航打开背包：同一套 Tab 逻辑，**游戏暂停**。

新档赠送迷你铜锣烧×2、能量牛奶×1（与配表表0「初始赠送」一致），方便前几关试携带。

## 2.8 商城页

**要什么效果：** 买得起、买完背包里能看到；买不起有提示。  
**怎么做成：**

- Tab：角色 / 道具 / 箱钥。  
- 点卡片 → 详情弹层：价格、说明、购买。  
- 扣款写存档，顶栏刷新；货币「+」→ 无充值说明（2.9）。  

买卖规则与货币类型 → **1.6**；具体价格在配表填数。
